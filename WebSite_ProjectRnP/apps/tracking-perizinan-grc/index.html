A. File Bersama Otomatis (Chrome / Edge)

Simpan satu file JSON di drive bersama (SharePoint / Google Drive Desktop / folder jaringan). Setiap anggota menghubungkan file yang sama, lalu cukup tekan ↓ Tarik sebelum mulai dan ↑ Simpan setelah selesai.

  1. Satu orang: Buat file bersama baru → simpan di drive bersama.
  2. Anggota lain: Hubungkan ke file bersama → pilih file yang sama.
  3. Sebelum mengedit: ↓ Tarik. Setelah selesai: ↑ Simpan.

A. File Bersama (browser ini)

Browser ini tidak mendukung tulis-file langsung. Gunakan cara manual di bawah.

B. Manual (semua browser) — Ekspor / Impor

  1. Isi Nama Anda di kanan atas (distempel pada perubahan).
  2. Impor file bersama → pilih Gabung agar pekerjaan tim tergabung.
  3. Edit progress / checklist / tindak lanjut.
  4. Ekspor dan timpa file bersama di drive.
Penggabungan (merge): menggabungkan kemajuan dari banyak orang — centang & tindak lanjut digabung, status diambil yang paling maju. Centang yang dibatalkan tidak ikut tergabung. Untuk menghindari bentrok, sebaiknya satu file dipegang sebagai acuan dan koordinasikan jadwal edit.
