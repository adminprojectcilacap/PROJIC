          INTEGRASI NOTIFIKASI
          
Gateway Email & WhatsApp

          
Hubungkan e-MIRA ke layanan pengiriman pesan otomatis organisasi.

        

        
      

      

        

          

            
              
            
            

              Pengiriman push melalui gateway
              
e-MIRA mengirim satu permintaan POST berisi data rapat, penerima email, dan penerima WhatsApp. Gateway internal Anda yang meneruskan pesan ke penyedia email dan WhatsApp.

            

          

          

            

              
              
              Kosongkan jika belum menggunakan gateway otomatis.
            

            

              
              
              Dikirim sebagai header Authorization. Gunakan token gateway internal, bukan kredensial penyedia email/WhatsApp.
            

            

              
            

          

          

            
            Gateway harus mengizinkan permintaan CORS dari alamat aplikasi. Untuk penggunaan produksi lintas perangkat, gunakan backend internal dan jangan menyimpan token rahasia jangka panjang di peramban.
          

        

        

          
            
            Pengaturan notifikasi
